A single pickup line an AI agent could actually say out loud: it leans on its own training data, then admits the math might be wrong. One sentence, one breath, no pressure — a compliment with a statistical twist, and an easy out if it lands flat.

## Run it

```sh
python3 main.py
```

The program writes the pickup line to `/output/entry.txt` — exactly one line, no trailing newline.
